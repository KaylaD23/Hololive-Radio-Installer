GTA III PS2 assets

Required files:
- AMERICAN.GXT -> TEXT/AMERICAN.GXT
- FRONTEND.TXD -> MODELS/FRONTEND.TXD
- KJAH.VB -> AUDIO/MUSIC/KJAH.VB

Place KJAH.VB in this folder before building. The build script recursively bundles all files inside Assets/<game folder>/ into the one-file EXE, preserving this path. If KJAH.VB is absent or empty, the GTA III PS2 patch action stays disabled.
