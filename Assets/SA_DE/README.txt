Optional Hololive Radio payload folder for GTA Vice City - The Definitive Edition.

Place the licensed 500-HololiveRadio_P.pak file in this folder before building the EXE.
Source folder: Assets/SA_DE/500-HololiveRadio_P.pak
Installer destination under the selected GTA Vice City - The Definitive Edition game root: Gameface/Content/Paks/~mods/500-HololiveRadio_P.pak

The Windows build script bundles all files under Assets/ while preserving their folder paths.
This project archive does not fabricate or include the .pak payload unless supplied separately.
