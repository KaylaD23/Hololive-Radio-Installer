GTA San Andreas classic PC TK station payloads

Required files for the SA PC install action:
- TK -> audio/streams/TK
- TrakLkup.dat -> audio/CONFIG/TrakLkup.dat
- fronten1.txd -> models/fronten1.txd
- american.gxt -> text/american.gxt

Place all four files in this folder before building. All present files under Assets/ are embedded into the EXE with their relative path preserved. TK and TrakLkup.dat must belong to the same mod package; TrakLkup.dat must have a byte size divisible by 12.
