Game payload bundling notice

All available game payloads belong in the game-specific folders under Assets/ (for example, Assets/VCS_PS2 or Assets/SA_PC). The Windows build script embeds every file found under Assets/ into the one-file EXE with its folder path preserved. Files with the same name are kept separate by game folder; the installer only loads a payload from the folder for the selected game.

The asset folders in this project may be incomplete. Every payload required by a specific game workflow must be present and non-empty before building to enable that action. The build process does not create or infer missing payloads.

Game data, mods, UI artwork, Hololive materials, GTA trademarks, and audio may be subject to rights separate from the GPL-licensed source code. Distribute only content you are authorized to redistribute.
GTA III PS2: AMERICAN.GXT and FRONTEND.TXD are provided under Assets/III_PS2. KJAH.VB must be supplied locally in Assets/III_PS2; the EXE build script bundles it automatically when present.
